# កម្មវិធីរចនាក្របសៀវភៅសិស្សបែបខ្មែរ (Khmer Student Notebook Cover Studio)

វេបសាយបង្កើត និងរចនាក្របសៀវភៅសិស្សបឋមសិក្សាកម្ពុជា ដែលបានសិក្សាស្រាវជ្រាវពីគំរូដើម **[coverbookkide](https://coverbookkide.vercel.app/)** រួចអភិវឌ្ឍបន្ថែមឱ្យកាន់តែសម្បូរបែប មាន**លក្ខណៈបែបខ្មែរពិតប្រាកដ** (Authentic Khmer Aesthetics) ទាំងក្បូរក្បាច់បុរាណ វប្បធម៌ និងស្តង់ដារអប់រំជាតិ។

---

## 🌟 លក្ខណៈពិសេសចម្បងៗ (Key Features)

### ១. រចនាបថ និងក្បាច់បែបខ្មែរពិតៗ (Authentic Khmer Art & Heritage)
- **ក្បាលក្រដាសជាតិ (National Header)** ៖ មានជម្រើសបិទ/បើកចំណងជើង «ព្រះរាជាណាចក្រកម្ពុជា» និងពាក្យស្លោក «ជាតិ សាសនា ព្រះមហាក្សត្រ» អមដោយសញ្ញារលកក្បាច់ និងត្បូងមាស។
- **ក្បាច់ភ្ញីទេសរាជវាំងមាស (Royal Golden Kbach Phnhi Tes)** ៖ ក្បាច់រំលេច ៤ ជ្រុង គែមភ្លោះមាសអភិជន និងក្បាច់កញ្ចាំងត្រីស៊ូល។
- **ក្បាច់អង្គរវត្ត & ផ្កាឈូក (Angkor Wat Heritage & Lotus)** ៖ រំលេចរូបចម្លាក់ប្រាសាទអង្គរវត្តមាស និងផ្កាឈូកទិព្វ។
- **ផ្ការំដួលជាតិខ្មែរ (National Romdoul Blossom)** ៖ រំលេចផ្ការំដួលតំណាងជាតិខ្មែរ ៤ ជ្រុង។
- **ក្រឡាសៀវភៅសិស្សកម្ពុជា (Khmer Ruled Notebook)** ៖ ក្រឡាហ្គារ៉ូសៀវភៅសិស្សខ្នាតស្ដង់ដារ បន្ទាត់ក្រហម-ខៀវ និង Washi Tape តុបតែង។
- **ស៊ុមទង់ជាតិ & បូកិត្តិយស (Cambodia National Flag Ribbon)** ៖ ឆ្នូតខៀវ-ក្រហម-ខៀវ និមិត្តរូបមោទនភាពជាតិ។
- **ម៉ូតស៊ុមបន្ថែម** ៖ គំរូផ្កាឆ្នូតប៉ាស្ទែល (PDF Replica), ផ្កាប៉ាស្ទែល, កាឡាក់ស៊ីអវកាស, ឥន្ទធនូរីករាយ, បូកិត្តិយស និងអាច Upload ស៊ុមផ្ទាល់ខ្លួនពីកុំព្យូទ័រ (PNG / JPG)។

### ២. មុខវិជ្ជាស្ដង់ដារ និងការបន្ថែមមុខវិជ្ជាថ្មី (Subjects Suite)
- មានស្រាប់នូវមុខវិជ្ជាបឋមសិក្សាទាំង ១២ ៖
  1. ភាសាខ្មែរ
  2. សរសេរតាមអាន
  3. គណិតវិទ្យា
  4. តែងសេចក្ដី
  5. វិទ្យាសាស្ត្រ
  6. សិក្សាសង្គម
  7. ភាសាអង់គ្លេស
  8. គំនូរ & សិល្បៈ
  9. សីលធម៌ & ពលរដ្ឋ
  10. កិច្ចការផ្ទះ
  11. ព័ត៌មានវិទ្យា (ICT)
  12. អប់រំកាយ & កីឡា
- ប៊ូតុង **"➕ បន្ថែមមុខវិជ្ជា"** ៖ អាចបង្កើតមុខវិជ្ជាថ្មី កែសម្រួល ឬលុបចេញតាមចិត្ត រក្សាទុកក្នុង LocalStorage។

### ៣. អក្សរកោង & ពុម្ពអក្សរខ្មែរ (Curved Typography & 35 Color Styles)
- **ម៉ូតពណ៌អក្សរស្អាតៗចំនួន ៣៥ ម៉ូត (35 Pre-designed Text Styles)** ៖ មានស្រាប់នូវម៉ូតពណ៌ Gradient គែម Stroke និងពន្លឺ Glow បែបមាសរាជវាំង, អង្គរវត្ត, ត្បូងទទឹម, ត្បូងមរកត, នេអុងទំនើប, ផ្កាសាគូរ៉ាប៉ាស្ទែល, ភ្លើងឆេះ, ឥន្ទធនូកុមារ, ខ្មៅរលោងគែមមាស និងជាច្រើនទៀត ដែលអាចចុចដាក់លើអក្សរភ្លាមៗបានដោយគ្រាន់តែចុច ១ Click!
- **បញ្ចូល Font ពីកុំព្យូទ័រផ្ទាល់ខ្លួន (Local Computer Fonts)** ៖ ប៊ូតុង `💻 បញ្ចូល Font ពីកុំព្យូទ័រ` អាចបញ្ចូលពុម្ពអក្សរ `.ttf`, `.otf`, `.woff`, `.woff2` ពីក្នុងកុំព្យូទ័ររបស់អ្នកយកមកប្រើប្រាស់លើក្របសៀវភៅបានភ្លាមៗដោយមិនបាច់ដំឡើងអ្វីទាំងអស់!
- **គាំទ្រពុម្ពអក្សរខ្មែរជាង ២០ Font** ពី Google Fonts (Moul, Koulen, Angkor, Bayon, Preahvihear, Battambang, Siemreap, Kantumruy Pro, Dangrek, etc.)។
- **អក្សរកោងរលូនស្អាត មិនបាក់តួអក្សរ** (Curved Arc SVG textPath) អាចកំណត់កម្រិតកោងឡើងលើ ឬចុះក្រោម។
- **ចុច Drag & Drop** រំកិលទីតាំងអក្សរលើក្របបានដោយសេរី។

### ៤. ប្លង់បោះពុម្ព A4 ឆ្លាតវៃ (A4 Print Studio)
- ដាក់ **២ ក្របក្នុង ១ សន្លឹក A4 ផ្តេក** (ទំហំសៀវភៅសិស្សបឋមសិក្សាត្រឹមត្រូវ)។
- **Modes** ៖
  - បោះពុម្ពទាំង ១២ មុខវិជ្ជា (ស្វ័យប្រវត្តិចេញជា ៦ សន្លឹក A4)
  - បោះពុម្ព ១០ មុខវិជ្ជាបឋម (ស្វ័យប្រវត្តិចេញជា ៥ សន្លឹក A4)
  - រើស ២ មុខវិជ្ជាជាក់លាក់ដាក់ក្នុង ១ សន្លឹក
  - ២ ក្របដូចគ្នាក្នុង ១ សន្លឹក
  - ១ ក្របទំហំពេញ A4
- មានបន្ទាត់កាត់ (✂️ Cut Guides) និងកំណត់គម្លាតគែម (Margin)។
- បោះពុម្ពបានជា Vector ច្បាស់កម្រិតខ្ពស់ដោយមិនបែករូប។

### ៥. នាំចូលបញ្ជីសិស្ស និងសមកាលកម្ម Google Sheets (Batch Import)
- នាំចូលបញ្ជីឈ្មោះសិស្សពី **Excel ឬ CSV** ដើម្បីបំពេញឈ្មោះសិស្ស ថ្នាក់ទី និងឈ្មោះសាលាបានរហ័ស។
- មុខងារ **Google Apps Script Web App** សម្រាប់ Cloud Sync។
- មុខងារ **Export / Import JSON Backup**។
- ទាញយកជារូបភាព **PNG កម្រិតច្បាស់ (HD)** និង **JPG**។

## 🚀 របៀបបើកដំណើរការ (How to Run)

បើក Terminal ក្នុងថត `f:\bookcover` រួចដំណើរការ ៖

```bash
node server.js
```

រួចចូលទៅកាន់ ៖ `http://localhost:3000/` លើកម្មវិធីរុករក (Chrome, Edge, Safari, Firefox)។
